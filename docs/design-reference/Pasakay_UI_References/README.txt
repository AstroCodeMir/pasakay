PASAKAY UI REFERENCE SCREENS

This package contains six individual PNG reference images for the Pasakay web application.

1. pasakay_search_results.png - Ferry search results and live availability
2. pasakay_booking_summary.png - Passenger and vehicle details with fare summary
3. pasakay_booking_confirmed.png - Booking confirmation and QR e-ticket
4. pasakay_operator_dashboard.png - Shipping operator dashboard
5. pasakay_travel_advisories.png - Travel advisories and service status
6. pasakay_mobile_view.png - Responsive passenger experience in a mobile browser

Notes:
- These are visual design references, not production-ready UI assets.
- Vessel names, fares, schedules, capacities, dates, and booking details shown are illustrative.
- Confirm real routes, operator data, fares, capacity rules, and regulatory requirements before implementation.
- Keep the web application responsive and use a shared backend/API for passenger, operator, and port workflows.
